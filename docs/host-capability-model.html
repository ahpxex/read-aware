2026-09-10 · 目标模型与现状映射；不是 API 已实现声明

ReadAware 宿主能力统一模型

沿用三类能力：Domain 是宿主拥有的业务状态与行为，Contribution 是插件向宿主提供实现，Service 是有边界的平台操作。Schema 只约束声明，不是第四类权力。Agent 与插件是这套模型的两个消费维度，不是两套宿主模型。

统一所有权，不无限扩张权限。

已有清单全部映射，尚未实现的入口仍明确标缺。临时计时器、复制聊天和导出格式优先组合，不为“完备”建设通用工作流或万能 API。

没有符合条件的条目。

统一模型

Agent 与插件共用业务所有权，不共用所有权限。Schema 只描述呈现，Contract 只约束执行；两者都不是新增权力。

D1 · 书库、集合与可寻址内容

目标：书籍/集合 list、get、查询、元数据修改、收藏、导入、删除、合并预览/提交、成员调整；TOC 树、章节正文、文本可用性、准备/重试、带位置的精确搜索、链接目标/图片资源解析。查询返回稳定对象引用与内容版本，搜索返回 snippet + Range，目录条目返回标题、层级、目标及可用编号元数据。

边界：章节编号解析、匹配排序、导出格式、RSS 订阅属于插件算法。章节 ordinal、书上印刷编号和 sectionIndex 不能混用。缺文件重导入目前只是普通导入流程，不承诺原 ID 原子替换。
