## SET04 开机启动

阶段一只通过纯序列化/原生提交顺序、受控 IPC、权限和挂载组件测试。
第二段为本行指定正式插件工作流，第三段该插件整轮必须包括：

- 记录隔离 app identifier、可执行路径和数据目录；启用前后确认生产
  ReadAware 的启动项未改变。普通及带空格/特殊字符的 packaged 路径均检查。
- 原生设置开启、Agent 关闭、授权插件开启：核对 OS 注册与 SQLite，
  重启应用仍一致；真实退出登录/登录证明开启会启动、关闭不会启动。
- Windows 核对 HKCU Run 和 StartupApproved；Linux 核对 XDG autostart、
  Exec 参数与桌面环境；macOS 核对 LaunchAgent plist 和登录限制。
  系统策略拦截不得拿“文件存在”冒充实际登录成功。
- 外部关闭启动项后修改语言/启动视图，不得重新开启；焦点返回刷新状态。
  原存储值与 OS 不一致时，关闭不能因 KV 无变化而成为空操作。
  安装路径移动或系统加入额外元数据后，已有启动项仍应可识别和关闭。
- 注入 OS 读取失败、写入部分失败、核验不一致、SQLite 批量事务失败、
  补偿失败；确认无虚假成功，原始信息只进日志，恢复后 UI/两端同源。
- 并发 UI/Agent/插件设置、队列中取消/撤权、卸载后迟到状态、双击、
  批量恢复/前缀替换/清空数据均验证；已派发 OS 操作不假称可撤销。
- 无路径权限的插件不可读写；包内 Worker 不得调用原始 autostart IPC；
  packaged CSP 与安装轮次保留对应证据。
- 收尾关闭隔离启动项并核对移除，保留生产启动项原始状态。测试证据
  必须记录平台/版本/路径/操作/实际结果，不能只贴 mock 测试通过数。

当前无上述真实轮次证据，SET04 保持“接通（待 E2E）”。

- Windows 注册表、Linux xdg 的真实注册/注销与处理器列表；默认应用
  和其他软件条目保持，安装/升级/卸载及独立 identifier 不污染生产。
- Windows NSIS 首次启动注册、更新后仍按持久开关、移动安装目录后的
  命令刷新、14 个 OpenWithProgids 的移除、卸载 ACL 拒绝不继续删除
  程序文件；旧 NSIS 通用类按命令/图标/标签确认归属再迁移，恢复备份
  不能覆盖后来选择的新默认。机器级旧关联需安装器迁移，不得假报注销。
