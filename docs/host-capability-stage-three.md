## OPS10 数据目录显示与 Reveal

代码入口：`maintenance 1.4 openSettings("data-location")` 与双 scope
`open_maintenance_settings`，宿主 `DataLocationGroup` / `nativeDataLocation`。

第三段必须检查：

- 从第二段覆盖 OPS10 的正式安装插件进入目录设置，确认显示的是隔离
  Tauri 数据目录，与该应用实际 SQLite/Blob 根目录相同，不是正式用户库。
- 插件和 Agent 返回值只有 `opened` 与 `surface`，不含目录、用户名、文件
  内容；定位时系统文件管理器不打开，必须由用户点击 Reveal。
- 点击 Reveal 后系统文件管理器确实显示对应目录；连续点击不重复派发
  同一在途 UI 操作。原生打开失败需捕获日志、稳定错误和本地化反馈。
- 目录查询故障不显示空目录或旧路径；瞬态错误重试恢复，权限错误不
  提供虚假重试。页面卸载、调用者退休/取消期间不交付迟到状态或定位。
- 在 packaged 轮次中通过正式插件安装重新验证该入口。截图/日志/IPC
  回执归入对应插件同一轮 evidence；macOS 的系统文件管理器行为不能
  外推为 Windows/Linux 已验。

目前证明仅为类型检查及针对性测试：调用了实际 Tauri JS API，但原生
IPC 为受控适配器，UI 是 JSDOM，未操作真实文件管理器。第二段尚未
指定正式插件流程，第三段结果与 evidence 路径仍为空，OPS10 保持
“接通（待 E2E）”。

## SET04 开机启动

阶段一只通过纯序列化/原生提交顺序、受控 IPC、权限和挂载组件测试。
第二段为本行指定正式插件工作流，第三段该插件整轮必须包括：

- 记录隔离 app identifier、可执行路径和数据目录；启用前后确认生产
  ReadAware 的启动项未改变。普通及带空格/特殊字符的 packaged 路径均检查。
- 原生设置开启、Agent 关闭、授权插件开启：核对 OS 注册与 SQLite，
  重启应用仍一致；真实退出登录/登录证明开启会启动、关闭不会启动。
- Windows 核对 HKCU Run 和 StartupApproved；Linux 核对 XDG autostart、
  Exec 参数与桌面环境；macOS 核对 LaunchAgent plist 和登录限制。
  系统策略拦截不得拿“文件存在”冒充实际登录成功。
- 外部关闭启动项后修改语言/启动视图，不得重新开启；焦点返回刷新状态。
  原存储值与 OS 不一致时，关闭不能因 KV 无变化而成为空操作。
  安装路径移动或系统加入额外元数据后，已有启动项仍应可识别和关闭。
- 注入 OS 读取失败、写入部分失败、核验不一致、SQLite 批量事务失败、
  补偿失败；确认无虚假成功，原始信息只进日志，恢复后 UI/两端同源。
- 并发 UI/Agent/插件设置、队列中取消/撤权、卸载后迟到状态、双击、
  批量恢复/前缀替换/清空数据均验证；已派发 OS 操作不假称可撤销。
- 无路径权限的插件不可读写；包内 Worker 不得调用原始 autostart IPC；
  packaged CSP 与安装轮次保留对应证据。
- 收尾关闭隔离启动项并核对移除，保留生产启动项原始状态。测试证据
  必须记录平台/版本/路径/操作/实际结果，不能只贴 mock 测试通过数。

当前无上述真实轮次证据，SET04 保持“接通（待 E2E）”。

## SET05 文件关联与系统文件接收

第一段尚未完成 Linux 运行时注册/注销，SET05 仍为部分。Windows 已接
HKCU 所有权注册、补偿及 NSIS 卸载清理，下面的真实安装轮次仍未执行。
本清单不替代该实现关闭条件。完成接线后，正式插件整轮须保留：

- macOS Info.plist 声明的 14 个扩展与 RunEvent::Opened 冷/热启动；
  关闭后收到文件不导入、不导航，运行中拒绝的文件不触发宿主 show/focus。
  关联声明仍保留，OS 仍可能启动/激活应用，冷启动仍会创建应用窗口。
- Windows 注册表、Linux xdg 的真实注册/注销与处理器列表；默认应用
  和其他软件条目保持，安装/升级/卸载及独立 identifier 不污染生产。
- Windows NSIS 首次启动注册、更新后仍按持久开关、移动安装目录后的
  命令刷新、14 个 OpenWithProgids 的移除、卸载 ACL 拒绝不继续删除
  程序文件；旧 NSIS 通用类按命令/图标/标签确认归属再迁移，恢复备份
  不能覆盖后来选择的新默认。机器级旧关联需安装器迁移，不得假报注销。
- UI、Agent、授权插件切换的持久化结果与 OS 行为一致；开启后新文件
  正常导入，关闭期间的文件和关闭前旧批次在重开后不复活。
- 在原生排队、读取文件信息、前端检查后到原生准入前、等待导入完成
  四个时间点关闭：前三个不再准入导入；已经原生准入的导入允许完成，
  导入后复核必须抑制迟到导航请求，不声称回滚已派发的导入或导航。
- 原生读取/注册/SQLite 提交失败、失败后重试、并发事件与撤权、冷启动
  首次挂载、清空数据与前缀恢复。保留原生日志、数据库、UI 和系统结果。
- 手动导入、拖放、readaware:// 登录不受本开关影响；packaged CSP 与
  正式插件安装仍需实测，不以受控 IPC/内存 SQLite 代替。
