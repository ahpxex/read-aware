ReadAware 插件能力完备基线

新插件应该组合公共能力，而不是继续给宿主补接口。当前缺的不只是操作入口，还有跨 Worker 的协议保真、数据一致性、取消与资源释放。

裁决：18 组、129 个能力验收项。两轮插件契约审计已记录，目标契约待实现、待验收；不是全部宿主能力都已覆盖。

第三轮：宿主 × Agent × 插件大表分别标记 212 行能力，反查 521 个注册库存条目，关联全部 129 个验收项。新发现包括 10 个只保存值、未找到效果消费者的设置，以及备份范围、画像和工具接线差异。完整事实与库存。

目标不是给插件原生权限，而是让内置 UI、Agent 和插件使用同一套产品操作。位置、结果、事件与生命周期必须接得起来。

入口有了，仍然可能不能用

以下 18 项全部未关闭。“高”优先阻断数据与执行正确性；“中”阻断组合和恢复；“待定 / 待证”不是已复现漏洞。每项源码、影响范围与关闭条件见细节版第 13 节。

高GAP01 · 更新回滚可能覆盖旧版的合法新写入

快照在旧版停写前取得；候选检查失败也会恢复快照。隔离探针确认了这个顺序窗口，未复现真实磁盘损失。

缺少停写、排空、一致快照和按阶段恢复；归属 O02/O05/R01。

高GAP02 · 迁移完成没有等待 KV 真正落盘

Worker 的 KV 写不在迁移等待队列里，宿主写与 schemaVersion 又是异步提交。

缺少持久确认屏障，写失败必须阻止迁移成功；归属 O01/O02/O05/R01。

高GAP03 · 写失败更正没有闭合到 Worker 镜像

宿主回滚通知和 Worker 同步不是同一路；旧写的晚失败还可能覆盖较新镜像。

缺少写序号、失败确认、按版本更正；归属 O02/Q02。真实锁库故障尚未注入。

高GAP04 · Request 的方法、头和正文跨桥丢失

公开类型接受 Request，桥接却只取它的 URL。隔离探针中 POST、头和正文变成了空 init。

缺少参数规范化与双向协议符合性；归属 P03/J12。未访问真实外部服务。

高GAP05 · 调用前已取消，仍会向宿主派发

探针记录到一次派发；调用后取消也只是停止等待，宿主请求继续。

缺少派发前检查、取消传播、终态回执；归属 P03/P04/Q06。取消不承诺撤回已提交的外部动作。

高GAP06 · 关视图没有释放 Worker 回调的协议

函数不断保留，handlers 仅在整个插件 deactivate 时清空；注销注册不等于释放闭包。

缺少按视图、注册和会话释放句柄；归属 E04/J10/N05/Q06/R03。

高GAP07 · 普通回调卡住时没有统一终态

激活、健康检查和迁移有超时，普通 invoke 没有；运行时异常也未统一拒绝 pendingInvokes。

缺少逐操作截止时间、失联收敛与诊断；归属 N05/Q04/R06。

高GAP08 · 禁用 Worker 不会自动停止宿主在途工作

权限屏障在入口检查，已开始的网络、推理或写入没有统一的所属任务取消管理。

缺少generation 校验、排空/中止与不可撤销结果；归属 Q06/R03/L02/P03。

中GAP09 · 另一设备的变化不走插件领域订阅

远端合并通过另一组 App 通知刷新内置 UI，插件没有对应的完整失效通路。

缺少带原因的失效通知和重取快照，不能重播历史触发自动化；归属 A06/F06/Q01/Q02。

中GAP10 · 旧动作结果可能覆盖或关闭新视图

detail dialog 有请求编号，普通动作没有同等代次保护；换根视图后旧结果仍可处理。

缺少视图身份、结果作废和过期 toast 抑制；归属 J04/J10/J12/Q06。

中GAP11 · 部分 async 订阅失败逃出隔离链

ignoreSelf 包装未返回 Promise，storage.onChange 只捕获同步异常；session/settings 已有异步处理。

缺少一致的观察者错误适配器；归属 Q01/Q05/R06。

中GAP12 · 业务 JSON 可能被误认成回调

含字符串 __fn 的普通对象会被 decode 当作函数引用，控制标记与业务字段未隔离。

缺少数据/回调分离和无损往返；归属 O01/P03/J12。

中GAP13 · 消息解码前缺统一 schema 和资源预算

方法解析已有原型链防线，但类型断言不是消息校验；视图 limits 不覆盖 RPC、HTTP 缓冲与回调队列。

缺少字节、深度、数量、并发和背压约束；归属 J12/P04/O04/R02。未实施真实压力攻击。

中GAP14 · provider 能注销，连接会话却无结束协议

同步传输 session 没有 close/dispose；移除注册不等于关闭已 open 的会话。

缺少会话归属、并发、替换和释放规则；归属 N04/N05/Q06。

待定GAP15 · 阅读元数据默认观察范围需要明确决策

session 当前不需独立权限，可订阅开书标题/作者和进度。这是现有默认授权，不是已证实的越权读取全书。

缺少默认公开范围、临时上下文与组合调用授权规则；归属 A01/A07/R02/P06。

待证GAP16 · Worker 隔离仍需打包桌面的安全证明

屏蔽若干全局 API 不证明所有出口均受控；动态模块、子 Worker 和剩余平台入口依赖实际配置。

缺少打包 Tauri 对抗验证；归属 R02/R03/P06。本轮没有复现沙箱逃逸。

中GAP17 · 稳定错误码尚未贯穿所有生命周期

普通 RPC 已保留 code，但激活、迁移及多个拒绝路径仍是裸 Error；通用 toast 无法区分修复方式。

缺少全阶段错误、关联 ID 和可恢复动作；归属 A05/J09/R06，复用现有错误体系。

中GAP18 · 版本和方法树检查不证明真实语义

当前 14 项相关单测全绿，仍能同时观察到协议和更新失败窗口。

缺少同一符合性用例贯穿共享层、Worker 和真实桌面；归属 R07/R08。

阅读与数据

A对象身份、位置与能力发现

必须有统一的书、章、范围、会话和资源引用；能力与可用性查询；操作回执和无丢失状态观察。

缺口目录索引不能直接交给定位接口；失效、版本与完成语义未统一。

B书库、集合与生命周期

已有书籍/集合读取、常用增删改和字节导入。

补齐批量结果、封面与原文件资源、可用性、导入进度/取消、去重合并流程和虚拟书刷新。

C正文、目录、搜索与资源

已有抽取章节目录和字符串正文。

补齐完整导航目录、精确搜索位置、跨书检索、抽取状态、分批/取消、附近文本、书内资源。

D阅读会话与统一导航历史

必须有当前会话、开关书与 ready、跳转回执、翻页/换章/进度、历史、沉浸与面板、格式支持的缩放。

缺口引擎已有搜索和历史，插件拿不到；现有打开/跳转只是发请求，缺最终反馈。

E选区与临时书内呈现

补齐读取/监听/设置选区、临时范围强调、片段/脚注/图片预览及释放。

底线临时搜索标记不冒充用户高亮，关视图或禁用插件就释放所属资源。

F高亮、笔记与问题轨迹

已有列表/搜索、高亮创建改色删除、笔记创建编辑删除。

补齐ID 读取、稳定分页/批量结果、任意合法范围互通、用户批准删除 ask、完整事件观察。

G阅读统计与会话记录

已有单书/全库/总览统计、读完状态修改。

补齐日期窗口、待结算时间和真实会话事件。宿主已有 book.sessionRecorded，插件公开类型尚未跟进。

H全量用户设置

已有精确路径授权、查询/批量修改、主题与声明式插件设置。

补齐文本对齐、固定版式原色、书架视图、快捷键、默认值与覆盖来源；凭据留在安全流程。

界面与智能

I应用导航、命令与挂载点

已有书架/阅读 header、选区/标注动作、命令与快捷键。

补齐现有产品页面/面板的语义导航、上下文槽位、侧面板、状态与可用性、类型化命令调用。

J可组合的声明式交互

已有列表、表单、详情和组合块，不是整个组件库的能力都已开放。

补齐异步搜索、稳定状态刷新、禁用/忙碌动作、多选/树/表格、通用 tabs、媒体、取消与视图生命周期。

K阅读模式与朗读控制

已有文本分段模式贡献、语音供应商和合成字节。

补齐模式启停、单元移动、朗读开始/停止与状态、声源选择、迟到结果和资源占用处理。

L推理与真实对话流程

已有一次性 LLM、结构化输出、文本增量、对话只读与 Agent 扩展贡献。

补齐取消/用量/限制、线程操作、草稿与问题交接、所属请求状态；不允许伪造消息或 system 提示。

M记忆、章节摘要与画像

缺口Agent 可访问有效记忆和章节摘要，插件没有对应领域读接口。

补齐授权读取、章节边界、候选处理回执、批准修订/遗忘、现有画像摘要和有来源的上下文导出。

N可替换提供者与内容来源

已有主题/字体、内容、语音、模式、Agent 扩展和密文同步传输。

补齐发现、依赖状态、修订刷新、可取消调用、健康和升级切换；跨插件不能借权。

资源与运行

O插件私有数据与资源

已有KV、文档集合、自有密钥、schema 迁移。

补齐真实提交回执、事务/冲突、二进制资源、配额、保留与备份策略；不暗示已经自动跨设备同步。

P文件、网络与外部系统

已有HTTP fetch、文本/二进制保存、剪贴板写。

补齐受控文件选择/分块读写、真正取消与 HTTP 流、受手势约束的剪贴板读/外部打开、敏感外发授权。

Q事件、自动化与后台任务

已有实时订阅、最低 15 分钟的 App 内周期调度。

补齐快照补读、当前会话短计时、任务进度/取消/并发、幂等和防自触发；关闭 App 不承诺运行。

R生命周期、安全与宿主管理

已有版本协商、激活屏障、资源注销、迁移与更新回滚。

补齐操作级授权与撤销、同步状态/正常同步请求、宿主管理确认流程、自有诊断，以及阻止公共能力再次遗漏的 CI。

没有匹配的能力条目。

不能把边界隐藏起来

X · 禁止直接开放的权力：任意 SQL/原生调用/文件路径、他人密钥、DOM 与脚本注入、静默购买/擦除/安装、伪造用户数据、跨插件借权、后台劫持交互和绕过 DRM。需要相应能力时走受控操作或宿主确认流程。

F · 当前宿主没有的能力：新解码器/引擎、通用 OCR/本地推理、自由画布/新图形原语、WebSocket/TCP、退出后守护任务、新原生设备权限、新共享数据模型、尚未完成的记忆管线、任意插件状态自动协同同步。

X 和 F 各有 9 项，完整清单逐项写明替代路径。插件的新算法、HTTP 服务、导出格式和私有书签，不算新增宿主能力。发现基线内接口缺失，应判为基线缺陷，不再换一个名字叫“新需求”。

什么情况下才算完成

完成条件：129 项逐项有实现和证据，18 个深入缺口全部关闭，32 个工作流验收通过。“已开放”项目关联的缺口同样阻止完成。注册表、类型检查和 mock 测试不能代替真实 Tauri 验收。

32 个场景覆盖 Jumper、搜索、导出、RSS、朗读、记忆和插件组合，也覆盖更新时并发写入、Request 保真、长期资源释放、卡死撤权、远端变化、乱序视图、消息预算与沙箱边界。

先统一对象与操作契约，再完整接入数据和阅读行为，随后补交互、AI/记忆、资源与任务。内置 UI 和 Agent 同步迁移，并加“产品操作不得绕过公共层”的门禁。

当前状态：目标契约待实现、待验收；未实施 Jumper 或宿主重构。14 项现有单测通过，三个隔离探针支持部分失败判断；未执行这 32 个 Tauri 产品场景，也未证明磁盘损失或沙箱逃逸。
