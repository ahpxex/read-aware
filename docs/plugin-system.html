Capability Architecture

插件能力，只有三种形状

读写产品状态走 Domain，扩展产品选择走 Contribution，需要宿主代办的外部操作走 Service。 插件动态加载，但权力边界由宿主定义。

架构参考：保留 2026-08-23 的三类划分；入口存在不证明完整语义、持久性、生命周期安全或桌面验收。

核对指引更新于 2026-09-09：统一目标与双端边界、实际接线矩阵、验收与 GAP01–GAP18。GAP 仍未关闭；本文对更新事务与旧结果隔离的概括不能视为所有失败路径已安全。

统一能力模型

Domain

ReadAware 已经拥有的状态和行为：查询、命令、事件、验证与持久化。

Contribution

插件提供的新动作、主题、语音、模式或内容实现；宿主负责消费和呈现。

Service

网络、模型、密钥、存储、计划任务等有边界的宿主能力，不是原生逃生口。

Domains

插件只看到权限允许的 actor view。所有写入都经过正式命令，并记录来源。

Settings 1.2 沿用单次更新的 SQLite 原子提交与双端持久回执，快照按授权过滤；失败回滚且不发成功事件。新增九项真实偏好：阅读对齐、固定版式配色、更新说明提示、内容字体四字段、默认标注色和更新通道。内容字体可跟随全局阅读设置或独立配置；默认色只影响新标注，更新通道只影响下次检查且不漫游。macOS debug 已验实际字体、FB2 标注、PDF 画布、已打开的更新面板与失败回滚；更新后重启、跨平台与这九项的打包验收仍未完成，完整带版本变更流也仍缺。

Agent 智能扩展

插件只能提供有边界的数据与候选，不能接管系统提示词或直接写长期记忆。

记忆构建开关已接通，Reading Goals 已实际消费两类贡献

buildMemory 关闭后，宿主停止 remember、候选、抽取、摘要、巩固和 digest 等记忆构建；排队与在途任务取消，重开不复活旧结果。聊天/历史和旧记忆仍可读取；已派发写不保证撤销。摘要保存/清除等待持久回执。

Reading Goals 按书保存目标并提供上下文，用户选择后才提出记忆候选；清除目标不删除已提升的记忆。源码十插件、编译内置六个，本插件不在内置清单且没有专属 Agent 目标编辑工具。macOS debug 已验双端、候选落库与失败取消；安装重启、打包/跨平台、键盘遍历与所有屏外控件仍未验。完整边界

版本与权限

每个 Domain、Contribution、Service 和声明式 UI schema 独立版本化。插件清单声明能力 semver 范围，也用整数 schemaVersion 管理自己的 KV 与文档数据。

权限控制“能不能做”

Domain 读写、网络、LLM、剪贴板、全局主题等需要语义化授权；Settings 使用精确路径。

版本控制“能不能正确做”

未知能力、无效范围、未获授权的依赖或不兼容版本都会阻止激活。

安全更新

独立暂存候选版本不会覆盖当前插件。
只读候选activate 只能读取和声明；挂载点先暂存，写数据、密钥、网络和业务命令都被阻止。
停写与快照先暂停并排空上一版，再取 KV、文档和 schema 快照；随后提交文件，刷新候选镜像并执行 storage-only 迁移。
显式提升健康与迁移都成功后，候选贡献才一次性进入全局 Registry。
按阶段恢复只有文件提交后才回滚文件、迁移可能写入后才恢复数据；健康检查失败不覆盖仍在运行的旧实例。恢复前停止并排空候选。
持久确认Worker 写与 schemaVersion 等待落盘；旧失败不抹掉新写，远端 origin 随持久写传递。跨界并发和真实桌面升级故障仍待验收，不宣称所有资源已安全释放。

始终不开放

插件运行在 Worker 中，界面由宿主声明式渲染。

RPC 已有 120 秒截止与每方向 256 个等待调用上限；Network v1.1 保留 Request 参数和二进制，每方向正文最多 64 MiB，取消与停用会传播到原生 HTTP。取消不撤销远端已发生的副作用。其他任务取消、回调所有权和生产 CSP 仍待验收，见 实现与桌面证据。

  • 任意 React、HTML、CSS、DOM、iframe 或 WebView 注入
  • 原始文件系统路径、SQLite、Tauri 命令与进程执行
  • Foliate 内部对象或通用未类型化 invoke
  • 绕过 Domain 命令直接修改产品状态
