Capability Architecture

插件能力，只有三种形状

读写产品状态走 Domain，扩展产品选择走 Contribution，需要宿主代办的外部操作走 Service。 插件动态加载，但权力边界由宿主定义。

已实现：统一目录、Settings Domain、只读候选激活、数据迁移、Agent 扩展与可回滚更新。

统一能力模型

Domain

ReadAware 已经拥有的状态和行为：查询、命令、事件、验证与持久化。

Contribution

插件提供的新动作、主题、语音、模式或内容实现；宿主负责消费和呈现。

Service

网络、模型、密钥、存储、计划任务等有边界的宿主能力，不是原生逃生口。

Domains

插件只看到权限允许的 actor view。所有写入都经过正式命令，并记录来源。

Domain负责什么插件范围
Library书、文件、元数据、目录、集合、导入与删除read / write
Reading当前阅读会话、位置、导航、进度与时长read / write
Annotations高亮与笔记read / write
Conversations书籍与全局对话摘要read
Settings设置目录、目标、校验、解析值与变更事件精确路径授权
Appearance 不是 Domain。它是 Settings 的一个 section。选择主题属于 Settings，提供主题属于 Theme Contribution。

Contributions

  • Selection / Header Actions
  • Commands / Agent Tools
  • Agent Context / Retrieval / Memory Candidates
  • Settings Options
  • Voice / Content Providers
  • Reader Modes
  • Themes / Fonts

Services

  • Storage / Secrets
  • UI export / Toast
  • Schedules / Session Events
  • Network / LLM / Clipboard

Agent 智能扩展

插件只能提供有边界的数据与候选，不能接管系统提示词或直接写长期记忆。

Contribution插件提供宿主把关
Context Provider当前问题相关的参考块来源标记、数量与长度限制、按轮注入
Retrieval Provider可搜索的插件私有数据标准查询工具、结果裁剪、按需调用
Memory Candidate可能值得记住的事实或洞见scope 校验、去重、正式 Memory 写入

版本与权限

每个 Domain、Contribution、Service 和声明式 UI schema 独立版本化。插件清单声明能力 semver 范围，也用整数 schemaVersion 管理自己的 KV 与文档数据。

权限控制“能不能做”

Domain 读写、网络、LLM、剪贴板、全局主题等需要语义化授权；Settings 使用精确路径。

版本控制“能不能正确做”

未知能力、无效范围、未获授权的依赖或不兼容版本都会阻止激活。

安全更新

独立暂存候选版本不会覆盖当前插件。
只读候选activate 只能读取和声明；挂载点先暂存，写数据、密钥、网络和业务命令都被阻止。
提交与迁移文件核对后暂停上一版，以 storage-only 权限执行 schema 升级或降级。
显式提升健康与迁移都成功后，候选贡献才一次性进入全局 Registry。
自动恢复失败时恢复上一版文件、KV、文档、schema 元数据和运行实例。
彻底释放订阅、贡献、任务、Provider 和 Worker 按代际安全销毁。

始终不开放

插件运行在 Worker 中，界面由宿主声明式渲染。

  • 任意 React、HTML、CSS、DOM、iframe 或 WebView 注入
  • 原始文件系统路径、SQLite、Tauri 命令与进程执行
  • Foliate 内部对象或通用未类型化 invoke
  • 绕过 Domain 命令直接修改产品状态
